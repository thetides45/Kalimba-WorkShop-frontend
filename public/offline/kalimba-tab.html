卡林巴转谱工坊

简谱 → 拇指琴专用谱 · 17 键 / 21 键 · 可点选、可试听

简谱输入
简谱语法速查
1 2 3 4 5 6 7音级（1 = 调号主音）
0休止符，不弹
.1   ..1低八度 / 低两个八度
1'   1''高八度 / 高两个八度
#4   b7升号 / 降号
1_   1__八分音符 / 十六分音符
1.附点（时值 ×1.5）；若后面紧跟别的音，请加空格：5. 6
1-   -延长一拍（延音线），可写在音符后，也可单独写
6_5_   1232连写：一个空格里可以写好几个音
[1 3 5]同一拍同时弹（双音 / 滑音）
|小节线
# 或 //整行注释

文件头指令（每行一条）：
title: 曲名 key: 1=C meter: 4/4 tempo: 66
tuning: 17（琴型 17/21） mode: movable（首调/固定调）
direction: up（从下往上/从上往下） transpose: 0（移调半音数）
★ 后四条「谱面转换」会自动写出来，点「生成琴谱」时自动加载回去。
多条谱行 = 多个声部，按小节与拍位自动对齐合并（主旋律 + 伴奏写两行即可）。

MIDI 导入

导入 .mid / .midi 文件，自动识别主旋律所在通道，按实际音高映射到琴键。识别不对时可在下方切换通道，谱子会重新生成。

MusicXML 导入

把 MuseScore / Guitar Pro 等导出的谱导入，按实际音高映射到琴键；超出音域的琴键点「⤢ 移调」调整。支持 .xml 与压缩的 .mxl，自动识别 UTF-8 / UTF-16 / GBK 编码。

附加设置
输入作者链接可预览
标题 / 作者印在每页页眉；二维码与附加信息排在每页右侧的信息栏（勾「分页预览」即可看到版式）。
